커머스 인사이트 화면 V3.5 + 수집기 5.1.0

[1] 수집기 5.1.0 (탬퍼몽키, 관리용 컴퓨터)
  1. 탬퍼몽키 대시보드 → '커머스 인사이트 수집기' 편집을 엽니다.
  2. 지금 GITHUB_TOKEN 따옴표 안의 토큰을 메모장에 잠깐 복사해 둡니다.
  3. 편집기 내용을 모두 지우고 collector\commerce-insight-collector.user.js 내용을 통째로 붙여 넣습니다.
  4. GITHUB_TOKEN 따옴표 안에 2번의 토큰을 다시 넣고 Ctrl+S.
  5. 다음 정각 수집부터 상품마다 판매가·할인가·옵션 추가금이 함께 기록됩니다. (네이버에 더 접속하지 않음: 이미 여는 상품 페이지에서 같이 읽음)

[2] 화면 V3.5
  1. 이 압축 파일의 commerce05.html 과 collector 폴더를 commerce-insight 저장소 폴더에 복사해 덮어쓰기
  2. GitHub Desktop 에서 Summary 에 "화면 V3.5, 수집기 5.1.0" 입력 → Commit to main → Push origin
  3. 2~5분 뒤 대시보드에서 Ctrl+F5, 오른쪽 위 버전이 V3.5 이면 끝

[3] 쓰는 법
  단가 관리 → 금액 기준(할인가/정가) 고르기 → [금액 불러오기] → 노란 칸(네이버 값과 다름)·틀린 칸만 고치기 → [적용 파일 내려받기] → 상품목록_적용.bat → Push
  합계 카드에는 '할인가 기준 매출'과 '정가 기준 매출'이 함께 나옵니다.

V3.4 내용(단가 입력 후 보던 줄에 머묾, [같은 상품 모두] 한 번 클릭)도 들어 있습니다.
